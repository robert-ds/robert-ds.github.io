---

## 🧠 ¿Qué es exactamente Arduino?

Arduino es una plataforma de desarrollo basada en una **placa con un microcontrolador** y un entorno de desarrollo (IDE) diseñado para facilitar el uso de la electrónica en proyectos multidisciplinares.

Se compone de dos partes esenciales:

* **Hardware:** La placa física con entradas (sensores) y salidas (motores, luces, pantallas) y un microcontrolador que actúa como su "cerebro".
* **Software (Arduino IDE):** El programa que instalas en tu computadora para escribir el código (basado en C/C++) y "cargarlo" en la placa a través de un cable USB.

👉 Permite controlar dispositivos físicos mediante código, sensores y actuadores.

## 🧩 Las Dos Funciones Fundamentales del Código Arduino

Todo programa en Arduino (llamado *sketch*) se divide en dos estructuras principales que se ejecutan secuencialmente:

```cpp
void setup() {
  // Se ejecuta UNA SOLA VEZ cuando la placa se enciende.
  // Ideal para configurar pines, iniciar sensores y conexiones.
  pinMode(13, OUTPUT);
}

void loop() {
  // Se ejecuta EN BUCLE INFINITO mientras la placa tenga energía.
  // Es el corazón donde vive la lógica del proyecto.
  digitalWrite(13, HIGH); // Enciende un LED
  delay(1000);           // Espera 1 segundo
  digitalWrite(13, LOW);  // Apaga el LED
  delay(1000);           // Espera 1 segundo
}

```

## ⚙️ El Ecosistema IoT y sus Aplicaciones Realistas

Arduino ya no se limita a proyectos escolares de encender LEDs. En el desarrollo moderno, se utiliza para:

* **Sistemas de Domótica:** Control de iluminación, cerraduras inteligentes y monitoreo de plantas o climatización.
* **Prototipado Industrial:** Creación rápida de pruebas de concepto para sensores de inventario o automatización de maquinaria.
* **Robótica:** Control de servos, motores paso a paso y robots autónomos.
* **Integración Web (IoT):** Utilizando placas modernas con conectividad Wi-Fi/Bluetooth (o módulos como el ESP8266/ESP32), Arduino puede enviar datos de sensores en tiempo real a una API REST, un broker MQTT o un dashboard web.

## 🚀 Arduino vs. Raspberry Pi (La Gran Confusión)

Es muy común confundirlos, pero responden a necesidades totalmente distintas:

* **Arduino (Microcontrolador):** Ejecuta **un solo programa en bucle continuo**. No tiene sistema operativo, consume ínfimos niveles de energía y es ultra rápido para reaccionar a señales electrónicas (como presionar un botón).
* **Raspberry Pi (Microordenador):** Es una computadora completa en miniatura con sistema operativo (Linux), procesador potente, salida HDMI y puertos USB. Puede ejecutar múltiples aplicaciones pesadas al mismo tiempo.

> **Regla general:** Si necesitas leer un sensor y mover un motor de forma inmediata, usa **Arduino**. Si necesitas procesar video, correr una base de datos o montar un servidor web, usa **Raspberry Pi**.

## 💾 ¿Por qué todo desarrollador debería probarlo?

Aprender Arduino cambia la forma en que entiendes la computación:

1. **Te enseña gestión de recursos rígida:** En la nube tienes gigabytes de memoria RAM; en un Arduino UNO tienes solo **2 KB de SRAM**. Te obliga a escribir código extremadamente eficiente.
2. **Entendimiento del hardware:** Comprendes conceptos clave como señales analógicas vs. digitales, interrupciones de hardware y protocolos de comunicación física (`I2C`, `SPI`, `UART`).
3. **Satisfacción inmediata:** Ver que una línea de código que escribiste en tu pantalla hace que un objeto físico se mueva en tu escritorio es una de las experiencias más gratificantes de la programación.
