>Si las placas anteriores son los "músculos" y "nervios" para interactuar con sensores y motores, la Raspberry Pi es un **cerebro completo**: un ordenador del tamaño de una tarjeta de crédito capaz de correr un sistema operativo Linux real.

Es una computadora de bajo costo y tamaño reducido diseñada para aprender programación, electrónica y desarrollar proyectos tecnológicos como automatización, servidores, robótica e Internet de las Cosas (IoT).

👉 A diferencia de Arduino o ESP32, Raspberry Pi es una **computadora completa**, capaz de ejecutar un sistema operativo y aplicaciones avanzadas.

---

## 🍓 Raspberry Pi: Un ordenador completo en la palma de tu mano

Mientras que un microcontrolador ejecuta un solo programa en bucle, la **Raspberry Pi** es una **Single Board Computer (SBC)** o computadora de una sola placa. Tiene procesador, memoria RAM, puertos USB, salida HDMI, tarjeta de red y corre un sistema operativo completo (normalmente Debian/Raspberry Pi OS).

Nació en el Reino Unido como un proyecto para enseñar informática en las escuelas, pero rápidamente fue adoptada por la comunidad global de ingenieros, administradores de sistemas y desarrolladores.

## 🧠 ¿Qué es exactamente una Raspberry Pi?

Es una computadora de placa única (**Single Board Computer - SBC**) desarrollada por la Raspberry Pi Foundation.

Todos sus componentes principales están integrados en una sola placa:

* Procesador 🧠
* Memoria RAM 💾
* Puertos USB 🔌
* Salida HDMI 🖥️
* WiFi y Bluetooth 📡
* Pines GPIO ⚡

A pesar de su tamaño, la Raspberry Pi (en sus versiones modernas como la 4 o 5) no le envidia mucho a una laptop básica de oficina:

* **Procesador ARM:** Chips de 64 bits de cuatro núcleos que ofrecen una potencia de cálculo sorprendente con un consumo de energía muy reducido.
* **RAM LPDDR4:** Opciones que van desde 1GB hasta 8GB, lo que permite ejecutar entornos gráficos completos o múltiples contenedores.
* **Pines GPIO (General Purpose Input/Output):** Es el conector de 40 pines que le permite interactuar con el mundo físico (como Arduino), combinando lo mejor del software y el hardware.
* **Almacenamiento via MicroSD / NVMe:** El sistema operativo y los archivos viven en una tarjeta MicroSD o en discos SSD externos M.2.

## 🖥️ Raspberry Pi OS y el Poder de la Terminal

Aunque puedes usarla con interfaz gráfica conectada a un monitor, el verdadero flujo de trabajo de un ingeniero es usarla en modo **Headless** (sin pantalla ni teclado conectados):

```bash
# Conexión remota por SSH a tu servidor Raspberry Pi
ssh pi@192.168.1.50

```

Desde la terminal tienes acceso completo a un entorno POSIX estándar: instala paquetes con `apt`, automatiza tareas mediante scripts de Bash o Python, o configura *cronjobs* para ejecutar procesos en segundo plano.

## 💻 Programación en Raspberry Pi

Permite programar utilizando múltiples lenguajes:

* Python 🐍
* C/C++
* Java
* JavaScript
* Node.js

Ejemplo en Python:

```python id="m8x3rt"
from gpiozero import LED
from time import sleep

led = LED(17)

while True:
    led.on()
    sleep(1)
    led.off()
    sleep(1)
```

👉 Controla un LED conectado a un pin GPIO.

## ⚙️ Casos de Uso Reales para Ingenieros de Software

Para un desarrollador backend o de sistemas, una Raspberry Pi es el laboratorio personal perfecto:

### 🏠 Servidor Doméstico (Home Server / Homelab)

Puedes montar un servidor Linux en tu casa para correr servicios como:

* **Pi-hole:** Un DNS sinkhole que bloquea la publicidad de toda tu red local a nivel de red.
* **Media Server:** Servidores multimedia como Plex o Jellyfin para transmitir tu contenido.
* **Nextcloud:** Tu propia nube privada personal sin pagar suscripciones a terceros.

### 🐳 Entorno de Pruebas Docker y Kubernetes

Al ser un sistema Linux real, puedes instalar Docker o distribuciones ligeras de Kubernetes (como **k3s**). Es el entorno ideal para practicar despliegues, probar microservicios o simular clústeres de servidores sin gastar crédito en AWS o Google Cloud.

### 🤖 Visión Artificial e Inteligencia Artificial Edge

Gracias a su puerto de cámara dedicado (CSI) y la potencia de su GPU/CPU, la Raspberry Pi permite procesar video en tiempo real usando librerías como OpenCV para reconocimiento facial, detección de objetos o lectura de matrículas.
