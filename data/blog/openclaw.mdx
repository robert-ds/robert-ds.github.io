>**OpenClaw** es un **asistente de inteligencia artificial de código abierto y autoalojado** que puede ejecutarse en tus propios dispositivos y conectarse con aplicaciones de mensajería, herramientas, modelos de IA y otros servicios. Su componente central es un **Gateway**, que funciona como puente entre el usuario, los modelos de IA y las diferentes herramientas/canales.

A diferencia de los asistentes cerrados tipo ChatGPT Web o Copilot, **OpenClaw es un *framework* / *gateway* multi-canal y agnóstico al modelo** que ejecutas en tus propios dispositivos (PC, servidor local o nube) y que se conecta directamente a tus apps de mensajería favoritas (WhatsApp, Telegram, Discord, Signal, Slack, iMessage).

👉 Actualmente, el proyecto está desarrollado de forma abierta bajo la **OpenClaw Foundation**, una organización sin fines de lucro.

---

## 🧠 ¿Qué problema intenta resolver?

Normalmente utilizamos la IA de esta manera:

```text
Usuario
   ↓
ChatGPT / Claude / Gemini
   ↓
Respuesta
```

El problema es que el modelo generalmente está separado de nuestro entorno de trabajo.

OpenClaw propone algo diferente:

```text
                    ┌───────────────┐
                    │   Modelo IA   │
                    └───────┬───────┘
                            │
                            ↓
┌─────────────┐      ┌───────────────┐
│ WhatsApp    │─────→│               │
│ Telegram    │─────→│    OpenClaw   │
│ Discord     │─────→│    Gateway    │
│ Slack       │─────→│               │
│ iMessage    │─────→│               │
└─────────────┘      └───────┬───────┘
                             │
                ┌────────────┼────────────┐
                ↓            ↓            ↓
             Archivos     Terminal     Web/API
```

El **Gateway** centraliza las sesiones, herramientas, eventos y conexiones con los diferentes canales.

## 1. Gateway

Es el **núcleo de control** de OpenClaw.

Gestiona:

* sesiones;
* conexiones;
* canales;
* herramientas;
* eventos;
* configuración;
* routing entre agentes.

## 2. Agente

El agente utiliza un modelo de IA para interpretar las instrucciones y decidir qué acciones realizar.

Puede trabajar con:

* contexto;
* memoria;
* herramientas;
* sesiones;
* múltiples agentes.

## 3. Canales

Una de las características importantes es que puedes interactuar con el agente desde diferentes aplicaciones.

Entre las integraciones documentadas se encuentran:

**Discord, Google Chat, iMessage, Matrix, Microsoft Teams, Signal, Slack, Telegram, WhatsApp, Zalo**, entre otras.

## 🔌 ¿Qué hace a OpenClaw diferente?

OpenClaw no es simplemente "un bot que responde preguntas". Es un **harness de agentes (*agent harness*)** con capacidades de ejecución de código, gestión de memoria persistente y automatización de tareas reales.

```text
 ┌─────────────────────────────────────────────────────────────┐
 │                    CANALES DE MENSAJERÍA                    │
 │    WhatsApp, Telegram, Discord, Slack, Signal, iMessage     │
 └──────────────────────────────┬──────────────────────────────┘
                                │ (Gateway OpenClaw)
                                ▼
 ┌─────────────────────────────────────────────────────────────┐
 │                OPENCLAW AGENT CORE & MEMORIA                 │
 │   • Memoria Persistente (SOUL.md, MEMORY.md)               │
 │   • Gestión de Sesiones y Contexto                          │
 │   • Habilidades (Skills), Cron Jobs y Webhooks              │
 └──────────────────────────────┬──────────────────────────────┘
                                │
          ┌─────────────────────┴─────────────────────┐
          ▼                                           ▼
┌──────────────────┐                        ┌──────────────────┐
│ MODELOS (LLM)    │                        │ HERRAMIENTAS Y   │
│ Claude, OpenAI,  │                        │ NODOS LOCALES    │
│ DeepSeek, Ollama,│                        │ Visión, Cámara,  │
│ LM Studio        │                        │ Terminal, Archivos│
└──────────────────┘                        └──────────────────┘

```

## 💻 Sus pilares principales:

1. **Agnóstico al Modelo (*Model-Agnostic*):** Puedes conectar OpenClaw a API de nube (Claude Opus/Sonnet, GPT-4o, DeepSeek) usando tus propias llaves o tu suscripción, o enlazarlo a modelos 100% locales mediante **Ollama**, **LM Studio** o **vLLM** para máxima privacidad.
2. **Multi-canal simultáneo:** Un solo proceso Gateway de OpenClaw atiende tus conversaciones en WhatsApp, Telegram, Discord, Slack o web sin duplicar instancias.
3. **Memoria y Contexto Persistente:** Utiliza archivos estructurados (como `SOUL.md` y `MEMORY.md`) para almacenar tus preferencias, aprendizajes de conversaciones previas e instrucciones globales. Tu asistente no "resetea" su cerebro al cerrar la app.
4. **Skills y Automatización (ClawHub):** Puede ejecutar código en tu terminal, leer archivos locales, consultar calendarios (CalDAV/Google), realizar raspados (*scraping*) web y ejecutar tareas programadas (*cron jobs*).

## 🔐 Autoalojamiento

Una de las características más importantes de OpenClaw es que puede ejecutarse en infraestructura controlada por el usuario.

En lugar de:

```text
Usuario
   ↓
Servicio externo
   ↓
IA
```

puedes tener:

```text
Usuario
   ↓
Tu computadora / servidor
   ↓
OpenClaw Gateway
   ↓
Modelo de IA
```

👉 La documentación describe OpenClaw como **self-hosted**, es decir, ejecutado sobre hardware bajo control del usuario.

Esto proporciona mayor control sobre:

* configuración;
* sesiones;
* herramientas;
* permisos;
* canales;
* infraestructura.

👉 **Importante:** autoalojar el Gateway no significa automáticamente que todos los datos sean procesados localmente; si utilizas una API de un proveedor externo, las solicitudes al modelo siguen dependiendo de ese proveedor.

## 💻 Instalación

OpenClaw actualmente puede utilizarse en **macOS, Linux y Windows**, y también existen rutas mediante Docker y otros métodos de instalación.

Una instalación rápida documentada es:

```bash
npx openclaw@latest
```

Después puede ejecutarse el proceso de configuración:

```bash
openclaw onboard --install-daemon
```

Y comprobar el Gateway:

```bash
openclaw gateway status
```

Finalmente:

```bash
openclaw dashboard
```

👉 abre la interfaz de control en el navegador.

## 🔗 Un caso de uso real: De enviar una foto a solucionar un problema

Imagina que estás en casa o en la oficina y necesitas resolver algo rápido:

1. **Vía WhatsApp / Telegram:** Le envías a tu OpenClaw una fotografía de un error en pantalla, una factura o una pieza rota.
2. **Capacidad Multimodal:** Tu nodo de OpenClaw procesa la imagen usando visión por computadora o el LLM seleccionado.
3. **Acción Real:** Si le pides *"Busca el manual de este equipo, extrae el error y envía un correo con el resumen a soporte"*, el agente ejecuta el flujo completo, genera el informe y te responde en el mismo chat confirmando que la tarea fue completada.

## ⚠️ Seguridad: un aspecto fundamental

Aquí hay que tener especial cuidado.

Un agente que solamente responde preguntas tiene capacidades limitadas.

Pero un agente que puede:

```text
leer archivos
     +
ejecutar comandos
     +
acceder a cuentas
     +
usar herramientas
```

puede realizar acciones reales sobre un sistema.

👉 La propia documentación de OpenClaw señala que un agente con acceso a credenciales, correo y comandos sobre computadoras requiere especial atención a la arquitectura y los controles de seguridad.

Por eso es importante configurar:

* 🔐 autenticación;
* 👤 usuarios permitidos;
* 📋 listas de acceso;
* 🧱 aislamiento/sandbox cuando corresponda;
* 🔑 permisos mínimos;
* 🌐 acceso remoto cuidadosamente;
* 📝 registros y monitoreo.
