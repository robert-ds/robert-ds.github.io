>El **ESP32** es un microcontrolador avanzado diseñado para proyectos de electrónica, automatización e **Internet de las Cosas (IoT)**

Lanzado por la empresa Espressif Systems, el ESP32 no es solo una placa de desarrollo; es un sistema en chip "SoC" ultra potente que resuelve la principal limitación del Arduino clásico: la conectividad inalámbrica nativa y la potencia de procesamiento.

👉 Combina un potente procesador con conectividad inalámbrica integrada como **WiFi y Bluetooth**, lo que permite crear dispositivos inteligentes conectados a internet.

* 🧠 Microprocesador
* 📡 WiFi
* 🔵 Bluetooth
* 💾 Memoria
* 🔌 Entradas y salidas GPIO
* 🔋 Gestión de energía

Todo en un solo dispositivo.

---

## 🔌 ESP32: El rey indiscutible del Internet de las Cosas (IoT)

Cuando pasas de encender un LED en un escritorio a querer monitorear la humedad de un invernadero en la nube, enviar métricas en tiempo real a una API o crear un dispositivo domótico inteligente, las placas tradicionales se quedan cortas.

El **ESP32** se ha convertido en la navaja suiza de los ingenieros de software y *makers* porque ofrece la potencia de un microordenador a un precio ridículamente bajo (unos pocos dólares), manteniendo el consumo eléctrico en órdenes de microamperios.

---

## 💡 Idea principal

Mientras que un Arduino tradicional necesita módulos externos para conectarse a internet, el ESP32 ya incorpora comunicación inalámbrica.

```id="a8m2qp"

    ↓

    ↓

  Usuario
```

## 🛠️ Programación del ESP32

Puede programarse utilizando:

* Arduino IDE
* PlatformIO
* MicroPython
* ESP-IDF

Una de las razones de su éxito masivo es su versatilidad de desarrollo:

1. **Ecosistema Arduino (C/C++):** Utilizando el entorno de siempre y reutilizando miles de librerías existentes.
2. **ESP-IDF:** El framework oficial de Espressif en C/C++ puro. Es el estándar para productos comerciales que buscan exprimir al máximo el rendimiento y la memoria.
3. **MicroPython / CircuitPython:** Permite escribir código en Python directamente en la placa, ideal para prototipado ultrarrápido.
4. Plataformas de desarrollo como **PlatformIO** que integran múltiples frameworks y facilitan la gestión de dependencias y despliegue.

## 💻 Ejemplo básico

Encender un LED:

```cpp
void setup() {
  pinMode(2, OUTPUT);
}

void loop() {
  digitalWrite(2, HIGH);
  delay(1000);

  digitalWrite(2, LOW);
  delay(1000);
}
```

👉 El ESP32 ejecuta instrucciones mediante código.

## 🛠️ ESP32 vs. Arduino UNO: Un salto generacional

Para entender por qué el ESP32 domina el mercado IoT, basta con comparar sus especificaciones técnicas frente al clásico Arduino UNO:

| Característica | Arduino UNO | ESP32 |
| --- | --- | --- |
| **Procesador** | ATmega328P (1 núcleo @ 16 MHz) | Tensilica Xtensa LX6 (**Doble Núcleo** @ 240 MHz) |
| **Memoria SRAM** | 2 KB | **520 KB** (Expandible) |
| **Conectividad** | Ninguna (requiere módulos externos) | **Wi-Fi (802.11 b/g/n) + Bluetooth 4.2 / BLE** |
| **Voltaje de Operación** | 5V | **3.3V** (Ojo con los sensores) |
| **Precio aproximado** | ~$10 - $20 USD | **~$3 - $6 USD** |

> **Nota para devs:** Mientras en un Arduino sufres si tu código supera unos pocos kilobytes, en un ESP32 puedes ejecutar un servidor web HTTPS interno, procesar JSONs complejos y conectarte a AWS IoT Core sin despeinarte.

## 🔌 El Superpoder del Doble Núcleo (FreeRTOS)

A diferencia de los microcontroladores básicos que solo pueden hacer una cosa a la vez, el procesador principal del ESP32 tiene **dos núcleos de 32 bits** (Core 0 y Core 1).

Por defecto, cuando lo programas con el ecosistema de Arduino:

* **Core 0:** Se encarga de gestionar la pila de red (mantener la conexión Wi-Fi viva, procesar paquetes TCP/IP, Bluetooth).
* **Core 1:** Ejecuta tu código principal (`setup()` y `loop()`).

Además, incluye de fábrica el sistema operativo en tiempo real **FreeRTOS**, lo que te permite crear **tareas multihilo (*tasks*)** concurrentes. Puedes tener un hilo leyendo un sensor a 100 Hz mientras otro hilo envía datos vía HTTP a un servidor sin que se bloqueen entre sí.

## ⌚ Características Avanzadas para la Industria

El ESP32 no solo es Wi-Fi; está repleto de periféricos de hardware diseñados para integraciones complejas:

* **Pines Capacitivos (Touch):** Cuenta con GPIOs que detectan el tacto humano directo sin necesidad de botones mecánicos.
* **Ultra Low Power (ULP) Co-processor:** Un tercer microprocesador enano que sigue encendido mientras el procesador principal está en "modo suspensión profunda" (*Deep Sleep*). Permite que el ESP32 consuma apenas **10 µA** y funcione durante años con una batería de litio.
* **Convertidores DAC y ADC:** Capaz de leer entradas analógicas con precisión de 12 bits y generar salidas analógicas reales.
* **Criptografía por Hardware:** Aceleradores integrados para AES, SHA-2 y RSA, esenciales para cifrar las comunicaciones a la nube (TLS/HTTPS).
